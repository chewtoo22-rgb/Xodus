# Aion Roadmap

## M0 — Contracts
- task/event protocol
- capability manifest
- permission decisions
- audit records
- provider interfaces

## M1 — Mock vertical slice
- shell prototype
- planner stub
- agent dispatcher
- mock Xodus Bridge
- end-to-end task with cancellation and audit output

## M2 — Local-first runtime
- local model adapter
- hardware/resource budgets
- deterministic tool-call validation
- provider fallback policy

## M3 — Safe Xodus bridge
- read-only system context
- file operations within user-approved scopes
- native application launch
- notifications
- settings allow-list

## M4 — Spaces
- persistent task workspaces
- app/file/web context grouping
- resumable task state
- export/import

## M5 — Labs Beta
- feature flag
- package/install boundary
- kill switch
- security tests
- performance tests
- offline tests
- hardware validation

## M6 — Graduation review
Promote individual components, not the entire experiment, into Xodus only after they independently satisfy Core release gates.
