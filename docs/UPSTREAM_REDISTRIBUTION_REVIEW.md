## Release check

Keep public ISO redistribution blocked until the actual image has been inventoried, missing upstream license terms and asset permissions are resolved, and the corresponding source and notices are available. A successful VM boot or hardware live test does not close this review.

The Core ISO artifact includes `xodus-payload-inventory.json`, `xodus-package-license-inventory.tsv`, and `xodus-asset-hashes.tsv` after a successful build. The JSON file records the ISO SHA-256, the checked-out Xodus commit, the pinned ISO and installer commits, file counts, and hashes of both TSV files. The package TSV reflects pacman's installed `%LICENSE%` metadata; that metadata alone is not proof that the shipped files have the stated license. The asset TSV hashes files and records symlink targets under license and wallpaper paths in the staged live root, plus the Ploader source, ISO-tree, and firmware boot-image EFI copies. It does not identify copyright owners or establish permission to redistribute those files. The inventory is generated from retained build staging and bound to the ISO SHA-256; reviewers must inspect the actual release candidate as well.
